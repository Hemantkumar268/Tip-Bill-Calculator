# Tip Calculator

A web-based Tip Calculator built with HTML, CSS, and JavaScript to calculate tips and split bills among multiple people.

## Features
- Preset tip percentage buttons
- Custom tip percentage input
- Bill total calculation
- Tip amount per person
- Total bill per person
- Input validation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
